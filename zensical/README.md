# zensical

Dagger module for building [Zensical](https://zensical.org) docs sites.

## Installation

Install into your workspace to add one `check` per docs site (`zensical.toml`) to `dagger check`:

```sh
dagger install github.com/typesafe-ai/daggerverse/zensical
```

## Usage

Build every docs site in the workspace:

```sh
dagger check --zensical
```

Learn more in [docs](https://daggerverse.docs.typesafe.ai/zensical).
