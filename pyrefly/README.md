# pyrefly

Dagger module that type checks Python with [Pyrefly](https://pyrefly.org), one check per uv workspace.

## Installation

```sh
dagger install github.com/typesafe-ai/daggerverse/pyrefly
```

## Usage

```sh
dagger check --pyrefly
```

Learn more in [docs](https://daggerverse.docs.typesafe.ai/pyrefly).
